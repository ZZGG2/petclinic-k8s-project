Public

Public Subnet

10.0.0.0/24, 10.0.1.0/24
  • Bastion Host — 관리자 SSH 접근 게이트웨이
  • Golden AMI — 표준화된 서버 이미지 배포
  • IGW를 통한 외부 인터넷 연결
Private

Private Subnet 1 — Web Tier

10.0.2.0/24, 10.0.3.0/24
  • Apache HTTPD 정적 웹 서버
  • 단일 index.html 페이지 서빙
  • WAS로 요청 프록시 전달
Private

Private Subnet 2 — WAS Tier

10.0.4.0/24, 10.0.5.0/24
  • Tomcat 애플리케이션 서버
  • Spring PetClinic 애플리케이션 구동
  • RDS와 내부 통신
Private

Private Subnet 3 — DB Tier

10.0.6.0/24, 10.0.7.0/24
  • Amazon RDS (MySQL)
  • WAS Tier에서만 접근 가능
  • 외부 인터넷 접근 완전 차단
